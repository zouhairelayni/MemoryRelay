# v3.3.2 — Chart metric dropdown

- Replaced Android native `HTMLSelectElement.showPicker()` with an app-owned listbox.
- Keyboard (Arrow, Home, End, Escape), outside-press dismissal, selected state and bounded scrolling.
- Activity period is a compact segmented control (24h, 7d, 30d, 90d).
- Chart metrics and per-function filtering still use the same monitored source data.
