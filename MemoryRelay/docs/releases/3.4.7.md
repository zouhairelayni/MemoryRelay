# v3.4.7 — React welcome animation and motion quality

Date: 2026-11-23

Added one-time WelcomeSplash using composite-only opacity/transform. Startup display minimum 850 ms, bypassed for reduced motion; authorization loading still respected. Removed excessive per-row stagger, introduced minimal dropdown/repository transition and bumped the service worker cache.

## Release verification

This feature is included in the v3.4.7 combined source package. The combined source tests report **165 passed, 0 failed, 1 skipped**. A production build was not run successfully in this sandbox because Vite dependencies were not installed; the installer requires `npm run build` before commit/push. Visual QA used headless browser fixtures with sample data, not the authenticated app.
