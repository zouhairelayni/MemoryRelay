# v3.3.4 — Structured memories with safe Markdown

- Memory cards have clear headlines, accessible expand actions, formatted details, and tagged provenance.
- Supports headings, bold/italic emphasis, bulleted or ordered lists, blockquotes, inline code, and fenced commands.
- Fenced commands get copy buttons; the page never executes code. Markdown HTML is displayed as text, not injected.
- Editor now provides formatting shortcuts and preview. No third-party Markdown HTML sanitizer or dependency is required.
- Database schema remains unchanged; formatting is stored as plain Markdown.
