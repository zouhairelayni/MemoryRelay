# v3.3.6 — MCP metadata and Markdown enforcement

- MCP `tools/list` advertises the current owner-configured estimated-token limit for both `remember` and `update_memory`.
- MCP `initialize` includes the live limit. `get_memory_settings` can be called to get the current limit at execution time.
- Metadata explicitly distinguishes estimated tokens from characters, and provides Markdown formatting instructions.
- Incoming agent text without Markdown structure is normalized to a **bold heading** and a labeled *Detail* bullet; already formatted Markdown is preserved. Owner-authored text and existing records are not changed.
- Validation runs against the *stored formatted result* and respects the configured 100–8,000 token bound.
- MCP clients may cache tool metadata; reconnect/reload the connection after deploying to refresh the advertised description. The enforcement setting itself is read per request and does not require redeployment.
