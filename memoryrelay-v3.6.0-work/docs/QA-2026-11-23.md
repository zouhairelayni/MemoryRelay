1. `npm ci` if dependencies are missing or stale; then `npm test && npm run build`.
2. Run `npm run dev:live`; sign in, inspect Live/Home chart, dropdown, all eight usage stats, and long repository names.
3. Install/open PWA; ensure Refresh is beside Settings and absent in browser mode.
4. Edit Markdown memories, use code-copy, confirm no unsafe HTML renders and no untrusted command ever executes.
5. Change memory context to a distinctive value, e.g. 2,000 estimated tokens. Reconnect your MCP client, use `get_memory_settings` and `tools/list` and verify the effective bound. The client may cache its old descriptions.
