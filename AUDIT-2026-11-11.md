# MemoryRelay audit, 2026-11-11 (all patches done, 134 tests pass)

## Why skills stayed stuck / GitHub said 403
- A sync checks 8 files per run. Cron only resumed repos with auto-sync ON, so repos with auto-sync OFF stayed at 8/27, 8/18, 8/10 forever. Cron now resumes any started queue; "Sync now" in the app keeps going until finished.
- A failure stamped last_checked, so cron waited 24 h before retrying a repo that never synced. Now: retry after 10 min; the 24 h wait only follows a successful check.
- A skill whose SKILL.md name differs from its folder (taste-skill) or a file that 404s froze the whole queue. Now it is skipped and listed under the repo ("sync_note").
- 403: without GITHUB_TOKEN GitHub allows 60 requests/hour per shared Cloudflare address, so the quota is often already used by others. Now: the Worker pauses ALL repos until GitHub's reset time (no wasted requests), uses ETag (304 replies are free), takes a lease so cron and the app never double-run, and shows the reset time in the app. Adding a GITHUB_TOKEN secret (npx wrangler secret put GITHUB_TOKEN) is the real fix: 5,000/hour.

## "ponytail / ponytail-audit do not exist"
Agents could only reach skills through select_skills (a ranker with 3 slots, and the AI could answer "none"). Now: a skill named in the request is always sent, new tools get_skill (exact name, explains unknown or switched-off) and list_skills, and the empty answer tells the agent to check before concluding a skill is missing. Update your agent's connector so it sees the two new tools.
NOTE: skills added from GitHub never replace a pasted skill of the same name; that is now listed in the repo note.

## Lag
- Built-in seeding never marked itself done: ~6 D1 reads + 1 write on EVERY request. Fixed.
- Skills list loaded every full body (official skills are huge) and an unindexed join; now reads 30 KB per skill and has an index.
- Every dashboard poll wrote an activity row and the table was never pruned; now only changes/failures are logged and rows older than 90 days are deleted hourly.
- select_skills could wait up to 150 s on the AI; now capped at 14 s, then keywords. Gemini key rotation no longer costs 2 D1 calls.
- GitHub sources screen polled every 12 s even when hidden; now only when visible.

## Security
- local.db in the zip held a plaintext admin password: removed; *.db ignored. Change any real password that was ever the same.
- server.js dev stub accepted any login with CORS "*": now loopback + localhost origins only, labelled dev-only.
- Login lock never reset after expiry (one typo = another 15 min); fixed, expired rows pruned.
- Memory import read an unbounded body: capped at 12 MB.
- get_skill_script / get_skill_resource ignored the on/off switch: now enabled skills only.
- GitHub text: hidden direction-changing/zero-width characters are refused; unattended updates that newly add injection-style wording are held back for your review (manual Sync now applies them with a warning).
- A Gemini 403 for one model no longer disables the whole key.

- Delegation deadline (previous audit item 5) untouched.
