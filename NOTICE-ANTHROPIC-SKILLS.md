# Adapted skill provenance

MemoryRelay's `worker/anthropicSkills.js` contains independently written, shorter instructions designed for MemoryRelay's existing Skill Genie. Skill themes and names were informed by Anthropic's public `anthropics/skills` repository:
https://github.com/anthropics/skills

This distribution does not bundle Anthropic's original skill source, Python helper scripts, proprietary fonts, logos, trademarks or images. The two Python templates are newly written for MemoryRelay and need external dependencies only when a host actually runs them. `doc-coauthoring` is an independent workflow rather than a copy of any source text.

Anthropic's repository includes Apache-2.0-licensed example skills, and separate third-party/trademark rights may apply to upstream artwork or branding. MemoryRelay's `brand-guidelines` adaptation is brand-neutral; it does not incorporate or confer any Anthropic trademark rights.
